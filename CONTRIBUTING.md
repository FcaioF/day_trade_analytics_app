# Contributing Guidelines

Thanks for your interest in contributing to this project. Follow these steps when you want to add a feature, fix a bug, or improve the docs:

1. Fork the repository and create a new branch for your work:

```bash
git checkout -b feature/short-description
```

2. Run tests and linting locally (if any) and ensure consistent code style.
3. Add unit tests for new functionality.
4. Create a pull request with a clear description of your changes.
5. Include a short demo screenshot or a brief description of the change for reviewers.

---

Notes:
- Use small changes per PR for easier review.
- For Terraform changes, validate in a sandboxed AWS account.
